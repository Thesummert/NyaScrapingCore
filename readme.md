# NyaScrapingCore

NyaScrapingCore 是一个使用 Rust 编写的 MCU 调试器前端核心，计划通过命令行提供交互，并对接外部调试工具，包括 OpenOCD、pyOCD 和 probers。

## 当前状态

项目处于结构设计阶段。目前只包含程序入口和模块占位，启动时显示开发状态；尚未实现命令解析、交互、调试会话、外部进程管理或任何后端通信。具体命令、后端协议和配置格式将在后续开发中确定。

## 项目结构

```text
NyaScrapingCore/
├── Cargo.toml          # Rust 包配置
├── readme.md
└── src/
    ├── main.rs         # 命令行程序入口
    ├── lib.rs          # 核心库入口
    ├── cli/            # 命令行交互（预留）
    ├── session/        # 调试会话管理（预留）
    └── backend/        # 外部工具适配（预留）
        ├── openocd.rs
        ├── pyocd.rs
        └── probers.rs
```

核心库和程序入口分开，以便后续由其他界面复用核心能力。各后端计划负责适配各自的外部工具；会话模块负责组织调试生命周期，命令行模块负责用户交互。具体边界会随功能实现调整。

## 构建与运行

需要安装 Rust 工具链（包含 Cargo），然后在项目根目录执行：

```sh
cargo build
cargo run
```

目前运行只会打印开发状态，不需要安装或启动任何外部调试工具。后续接入后端时，需要按对应工具的要求单独安装和配置。
